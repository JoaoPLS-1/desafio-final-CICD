COMO A ENTREGA FUNCIONA

O mesmo código.
Em cada etapa.

  1. Versionar

    A alteração nasce na branch feature/entrega-final e segue para revisão em um Pull Request.

  2. Validar

    O GitHub Actions verifica a página e testa a imagem antes do merge na main.

  3. Distribuir

    A imagem do site fica no GitHub Container Registry, com versão e referência ao código de origem.

  4. Executar

    O Podman baixa a imagem do Registry e serve o site na porta 9000, sem precisar copiar os arquivos do projeto.
